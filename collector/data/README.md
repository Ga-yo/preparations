# collector/data

`pois` job(`jobs/pois.py`)가 읽는 수동 갱신 CSV. 원본 파일은 커밋하지 않는다.

| 파일 | 데이터 | 기관 | 행 수 | 데이터 기준일 | 받은 날 |
|------|--------|------|-------|---------------|---------|
| subway_stations.csv | 전국도시철도역사정보표준데이터 (data.go.kr 15013205) | 국가철도공단 | 556 | 2020-12-18 ~ 2021-08-12 (행마다 다름, 최댓값 2021-08-12) | 2026-11-12 |
| schools.csv | 전국초중등학교위치표준데이터 (data.go.kr 15021148) | 한국교육시설안전원 | 4,439 | 2026-10-01 | 2026-11-12 |

- 원본: 두 데이터셋 모두 OpenAPI 없이 표준데이터 페이지의 파일 다운로드(`/download/columList.json`, `/download/standard.json`, 로그인 불필요)로 받은 전체 레코드(역 898행, 학교 12,004행)다. 포털의 원본 파일명은 `전국도시철도역사정보표준데이터`, `전국초중등학교위치표준데이터`.
- 이용허락범위: 역 데이터는 페이지 표기 "이용허락범위 제한 없음". 학교 데이터는 페이지에 범위 문구가 없고 포털 정책 링크만 있다(공공데이터포털 이용정책 따름).
- 추린 규칙
  - 역: 도로명주소(`RDNMADR`)가 서울·경기·인천으로 시작하는 행. 환승역은 노선마다 한 행이다. 원본 역번호(`STATN_NO`)와 노선번호는 중복이 있어(예: 경원선/경의중앙선) `station_id = "<노선명>:<역사명>"`(원본 전체에서 유일)로 만들었다.
  - 학교: 소재지 지번주소(없으면 도로명주소)가 서울·경기·인천이고 학교급구분이 초등학교·중학교·고등학교인 행. `level`은 원본 값 그대로, 운영상태 값은 전부 `운영`(job은 `운영`이 아니면 버린다).
- 알려진 한계: 역 원본은 2021년 기준이며 인천교통공사(인천 1·2호선), 신분당선, 공항철도, 서울 9호선 일부 등이 빠져 있다.
- 갱신: 파일을 새로 받아 위 규칙으로 CSV를 다시 만들고 `uv run python main.py pois`를 돌린다(역 연 1회, 학교 필요할 때). CSV에서 빠진 행은 DB에서 지워진다.
