# collector/data

`pois` job(`jobs/pois.py`)가 읽는 수동 갱신 CSV. 원본 파일은 커밋하지 않는다.

| 파일 | 데이터 | 기관 | 행 수 | 데이터 기준일 | 받은 날 |
|------|--------|------|-------|---------------|---------|
| subway_stations.csv | 도시철도역사정보 표준데이터 전체 기관판 `전체_도시철도역사정보_20260630.xlsx` (철도산업정보센터 data.kric.go.kr 파일데이터 id=32, data.go.kr 15093755 "국가철도공단_도시광역철도_역사정보"가 같은 파일을 가리킴) | 국가철도공단 | 776 | 행마다 다름 2022-04-30 ~ 2026-06-18(최댓값 2026-06-18) | 2026-11-12 |
| schools.csv | 전국초중등학교위치표준데이터 (data.go.kr 15021148) | 한국교육시설안전원 | 4,439 | 2026-10-01 | 2026-11-12 |

- 원본: 역은 철도산업정보센터(data.kric.go.kr) 파일데이터 `전체_도시철도역사정보_20260630.xlsx`(수정일 2026-07-06, 1,099행)를 받아 추렸다(`/rips/dataset/download.file?type=filedata&id=32&operation=1`, 로그인 불필요, data.go.kr 15093755 "바로가기"가 가리키는 파일). 학교는 OpenAPI 없이 표준데이터 페이지의 파일 다운로드(`/download/columList.json`, `/download/standard.json`, 로그인 불필요)로 받은 전체 레코드(12,004행)다. 15013205의 standard.json 합본(898행, 2020~2021 기준)은 더 오래되어 쓰지 않는다.
- 이용허락범위: 역(data.go.kr 15093755) 페이지 표기 "이용허락범위 제한 없음". 학교 데이터는 페이지에 범위 문구가 없고 포털 정책 링크만 있다(공공데이터포털 이용정책 따름).
- 추린 규칙
  - 역: 역사도로명주소가 서울·경기·인천으로 시작하는 행(777행)에서 노선명·역사명이 같은 완전 중복 1행(경인선 주안역)을 최신 기준일로 합친 776행. 환승역은 노선마다 한 행이다. 원본 역번호는 노선 간 겹치므로 `station_id = "<노선명>:<역사명>"`(유일)로 만들었다. 기준일이 비었거나 잘못된 13행은 파일 기준일 2026-06-30으로 채웠다.
  - 노선별 행 수: 1호선 10, 2호선 50, 3호선 34, 4호선 26, 5호선 56, 6호선 39, 7호선 43+11(도시철도 7호선), 8호선 19+2, 9호선 25+13(원본 노선명이 둘로 갈림), 신분당선 16, 인천지하철 1호선 33, 2호선 27, 인천국제공항선(공항철도) 14, 분당선 36, 경의중앙선 51, 수인선 26, 서해선 21, 경부선 34, 경원선 35, 경인선 20. GTX-A는 원본에 없다. 노선명 표기는 원본 그대로라 이름이 일관되지 않는다.
  - 학교: 소재지 지번주소(없으면 도로명주소)가 서울·경기·인천이고 학교급구분이 초등학교·중학교·고등학교인 행. `level`은 원본 값 그대로, 운영상태 값은 전부 `운영`(job은 `운영`이 아니면 버린다).
- 알려진 한계: GTX-A 없음. 노선명 표기가 원본 그대로 불일치("1호선"=서울교통공사 외 경부선 구간 포함 여부 등). 서울·경기·인천 주소가 아닌 구간(예: 경춘선 강원 구간)은 제외했다.
- 갱신: 파일을 새로 받아 위 규칙으로 CSV를 다시 만들고 `uv run python main.py pois`를 돌린다(역 연 1회, 학교 필요할 때). CSV에서 빠진 행은 DB에서 지워진다.
